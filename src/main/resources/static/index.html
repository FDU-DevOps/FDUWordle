How to Play

You have 6 attempts to guess the target word.

Each guess must be a valid 5-letter word

The grid and keyboard will update depending on your guess and how close the guess was.

Feedback Info:

M is in the target word and in the correct spot, so it shows as GREEN


O is in the target word, but not in the correct spot, so it shows as YELLOW


Keyboard feedback based on user guess and how accurate it is to the target word
